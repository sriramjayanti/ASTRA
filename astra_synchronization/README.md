# ASTRA Stage 6 — Synchronization Engine

## Overview
The **Synchronization Engine** is Stage 6 of the **ASTRA (Automated Signal Analysis & Recovery Assistant)** signal processing pipeline.

Its primary role is to take a **Receiver Hypothesis** generated by Stage 5 (Modulation $\times$ Baud) along with the raw IQ signal, and apply family-specific DSP synchronization routines to correct channel and receiver mismatches:

- **Coarse Carrier Frequency Offset (CFO)** (up to $\pm 0.20 F_s$)
- **Fine Carrier Phase & Frequency Rotation** (Costas loop / Decision-Directed PLL)
- **Pulse Matched Filtering** (Root-Raised Cosine RRC / Gaussian)
- **Symbol Timing & Clock Recovery** (Gardner TED + Mueller & Müller)
- **Non-Integer SPS Rational Resampling** (Polyphase resampling to working 2.0 SPS)
- **Frequency-Centric Synchronization for FSK** (Tone centering + Instantaneous Frequency Discriminator)
- **Multi-Dimensional Lock Assessment** (Timing lock, carrier lock, frequency lock, constellation compactness)

## High-Level Pipeline Architecture

```
Candidate Hypothesis (Stage 5) + Raw IQ Waveform
                     │
                     ▼
       ┌───────────────────────────────┐
       │   1. Signal Conditioning      │ (Canonical complex64, DC removal, Power norm)
       └─────────────┬─────────────────┘
                     │
                     ▼
       ┌───────────────────────────────┐
       │ 2. Coarse CFO Estimation/Corr │ (M-th power / Spectral Peak / Phase difference)
       └─────────────┬─────────────────┘
                     │
                     ▼
       ┌───────────────────────────────┐
       │ 3. Pulse Matched Filtering    │ (RRC with candidate rolloff α ∈ [0.20, 0.35, 0.50])
       └─────────────┬─────────────────┘
                     │
                     ▼
       ┌───────────────────────────────┐
       │ 4. Rational Polyphase Resample│ (Converts non-integer SPS to working 2.0 SPS)
       └─────────────┬─────────────────┘
                     │
                     ▼
       ┌───────────────────────────────┐
       │ 5. Symbol Timing Recovery     │ (Non-data-aided Gardner TED + M&M refinement)
       └─────────────┬─────────────────┘
                     │
                     ▼
       ┌───────────────────────────────┐
       │ 6. Fine Carrier/Phase Tracking│ (PSK: Costas Loop, QAM: DD-PLL, FSK: Centering)
       └─────────────┬─────────────────┘
                     │
                     ▼
       ┌───────────────────────────────┐
       │ 7. Lock Quality Assessment    │ (Multi-dimensional scoring & status evaluation)
       └─────────────┬─────────────────┘
                     │
                     ▼
           SynchronizationResult
   (Symbol Samples + Phase Ambiguity Info + Telemetry)
                     │
                     ▼
      Stage 7: Demodulation Engine (Hard & Soft Bits)
```

## Modulation Family Routing

ASTRA strictly avoids forcing incompatible DSP loops onto modulations:

| Modulation Family | Coarse CFO Method | Matched Filter | Timing Recovery | Carrier Recovery | Ambiguity States |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **PSK** (BPSK, QPSK, 8PSK) | $M$-th power nonlinearity ($M=2, 4, 8$) | Root-Raised Cosine (RRC) | Gardner TED + M&M | Costas Loop (orders 2, 4, 8) | $[0, \pi/2, \pi, 3\pi/2]$ |
| **QAM** (16-QAM, 64-QAM) | Spectral peak centroid | Root-Raised Cosine (RRC) | Gardner TED + M&M | Decision-Directed PLL | $[0, \pi/2, \pi, 3\pi/2]$ |
| **FSK** (2-FSK, 4-FSK) | Tone center estimation | Discriminator / none | Instantaneous freq peak comb | Tone center balancing | $[0]$ |
| **UNKNOWN** | Spectral peak | Pass-through | None | None | $[0]$ |

## Quickstart

```python
from astra_synchronization.src.inference import SynchronizationEngine
from astra_synchronization.src.utils import generate_synthetic_test_signal

# 1. Generate test signal with +1250 Hz CFO and timing offset
rx_iq, _ = generate_synthetic_test_signal(
    modulation="QPSK",
    symbol_rate_hz=9600.0,
    sample_rate_hz=192000.0,
    cfo_hz=1250.0,
    snr_db=20.0
)

# 2. Synchronize against Stage 5 Candidate Hypothesis
engine = SynchronizationEngine()
hypothesis = {
    "candidate_id": "cand_QPSK_9600_001",
    "modulation": "QPSK",
    "modulation_family": "PSK",
    "symbol_rate_hz": 9600.0,
    "sample_rate_hz": 192000.0
}

result = engine.synchronize(rx_iq, hypothesis)

print(f"Status        : {result.status}")
print(f"Estimated CFO : {result.estimated_cfo_hz:+.1f} Hz")
print(f"Sync Score    : {result.lock_metrics['overall_sync_score']:.4f}")
print(f"Symbol Samples: {result.symbol_count} constellation points ready for Demodulation")
```
